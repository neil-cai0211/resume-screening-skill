# P001 后端研发经理 简历筛选技能

这是「P001 后端研发经理」岗位简历筛选的可复用技能：按工作日定时从只读招聘邮箱收件，用 Workbuddy 按评分表打分，仅在指定轮次把推荐人打包后，经用户笔记本上的 dws 单聊发给招聘负责人，并向用户做极简汇报。

本仓库是脱敏发布版。真实邮箱、机器标识、dws 路径、密钥和候选人台账不要放进本仓库。运行参数见 `config.example.md`，真实值放在仓库外的私有配置里。

评分规则版本：**v4.7**。技能更新日期：**2026-11-18**（Asia/Shanghai）。完整步骤以 [`SKILL.md`](./SKILL.md) 为准，分值与档位以 [`references/评分表.md`](./references/评分表.md) 为准。

## 用途

- 适用：P001 后端研发经理 / 后端开发经理的简历初筛、推荐打包和内部汇报。
- 不适用：校招或其他岗位；薪人薪事 / EHR 操作；给候选人发拒信、面试通知或任何外部联系。

## 触发与排程

- 时区：Asia/Shanghai。
- 工作日 **10:00**、**17:30**，允许 ±15 分钟。
- 10:00：收件、去重、评分、暂存推荐材料，不发给招聘负责人；向用户极简汇报。
- 17:30：再收一次并评分；若有待发送的推荐，发一条 Markdown 汇总 + 一个 zip；然后汇报。没有待发送的推荐就不要发钉钉。
- 用户当场要求立即发送时，可以不等 17:30。
- 汇报只发给用户私聊。无新内容不通知。

## 依赖与配置参数

依赖（均由运行环境提供，本仓库不包含密钥或安装包）：

- 只读邮箱连接器，用于读取 `<GMAIL_ACCOUNT>` 自 `<RESUME_SINCE>` 起的岗位相关邮件。
- Workbuddy / codebuddy CLI：`<WB_CLI>`。默认模型 `<WB_MODEL>=hy4flash-free`，参数 `--tools "" --max-turns 1`，环境变量 `CODEBUDDY_INTERNET_ENVIRONMENT=internal`，单份超时 1800 秒。脚本见 `scripts/`。
- 用户笔记本及 dws：经 `<LAPTOP_MACHINE_ID>` 调用 `<DWS_PATH>`，先按 `<HIRING_MANAGER_QUERY>` 唯一解析联系人，再发文字和文件。

占位符与含义见 `config.example.md`。脚本读取环境变量 `WB_CLI`、`WB_MODEL`、`WB_WORK`、`WB_SESSION_DIR` 等，没有内置真实路径或密钥。

## 安全与脱敏

- 本仓库不得包含：密钥、token、凭证、真实邮箱或机器标识、候选人联系方式、真实简历或真实评分台账。
- 示例一律使用虚构占位（如「候选人甲」）。历史变更说明里的个案已改为「候选人A」等化名。
- 发给招聘负责人的内容只含三维度评语和已重命名的简历 PDF；不写手机号、邮箱、身份证、住址，不写面试追问。
- 给用户的汇报是极简三行（推荐 / 不合适 / 卡点 + Workbuddy 用量），不写联系方式和年龄。
- 邮箱只读。不要给外部发信。不要操作 EHR。dws 发送失败或笔记本离线时停止并报告，不要换通道。
- 更新本仓库前应再次扫描：密钥关键字、手机号和邮箱模式。
