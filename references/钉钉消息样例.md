# 发给招聘负责人的汇总消息样例（虚构）

每轮只发一条 Markdown 消息，外加一个只含本轮推荐 PDF 的压缩包。标题不要加「【测试】」。

```markdown
## P001 后端研发经理 简历推荐（2026-11-18）

本轮推荐 1 人，简历见附件压缩包 P001_简历推荐_20261118.zip。

### No.006 候选人甲

**技能知识：** 做过餐饮门店交易系统的拆分和灰度，能讲清回滚和对账补偿；近期仍有具体编码描述。服务治理写得较泛。

**过往履历匹配度：** 最近一段在餐饮 POS 相关公司做后端负责人，带过小组，订单和支付链路有本人参与的描述，与本岗位较贴近。

**学历年龄：** 本科学制四年，简历未写是否全日制，按四年口径视为符合；简历未写年龄。
```

压缩包内文件名示例：`006_候选人甲_示例餐饮科技.pdf`。
